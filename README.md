# 🗓️ Online Appointment Booking System

## 📌 Description  
A simple Python-based appointment booking system that allows users to book and view appointments using a menu-driven program.

## ⚙️ Features  
- Book appointment  
- View appointments  
- User-friendly interaction  
- Menu-based system  

## 🛠️ Technology  
Python

## ▶️ How to Run  

```bash
cd online-appointment-booking-system
python onlineapp.py
